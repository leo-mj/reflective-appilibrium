# RE Relations Reference

This file defines the possible relations between elements in a reflective equilibrium process. When a new element is added, check it against every existing element using the relevant rows and columns below.

## Relation Types

### Supports
Element A provides positive reason for Element B — evidential, explanatory, or logical.

### Conflicts
Element A and Element B are incompatible — holding both generates a contradiction or incoherence.

### Undermines
Element A weakens Element B without flatly contradicting it — reduces plausibility or confidence.

### Depends
Element A presupposes Element B — A cannot hold (or loses its grounding) if B is withdrawn.

---

## Relation Matrix

### Judgment → Judgment

| Relation | Description | Example |
|---|---|---|
| Supports | J₁ provides evidence or analogical support for J₂. Cases are relevantly similar and the verdicts reinforce each other. | "Torturing one to save five is wrong" supports "Harvesting organs from one to save five is wrong" — analogous structure, same verdict. |
| Conflicts | J₁ and J₂ give incompatible verdicts on relevantly similar cases, or one entails the denial of the other. | "Killing in self-defense is permissible" conflicts with "All intentional killing is wrong." |
| Undermines | J₁ weakens (but does not flatly contradict) J₂ — e.g., by introducing a relevantly similar case where the verdict differs, casting doubt on the rationale behind J₂. | "Lying to protect a friend feels permissible" undermines "Deception is generally wrong" — doesn't contradict it outright but reduces confidence. |

### Judgment → Principle

| Relation | Description | Example |
|---|---|---|
| Supports | J provides a case that P correctly accounts for — evidential support for the principle. | "Factory farming is wrong" supports "It is wrong to cause unnecessary suffering to sentient beings." |
| Conflicts | J is a counterexample to P — a case where the person's verdict contradicts what P prescribes. | "It is permissible to lie to a murderer asking for a victim's location" conflicts with "One must never lie." |
| Undermines | J weakens the plausibility of P without being a direct counterexample — e.g., a case where P gives the right verdict but seemingly for the wrong reasons. | "Helping a stranger feels obligatory even when no one is watching" undermines "Moral motivation is ultimately self-interested" — not a counterexample, but makes the principle less plausible. |

### Principle → Judgment

| Relation | Description | Example |
|---|---|---|
| Supports | P explains or justifies J — the principle accounts for why the judgment holds. | "Persons must never be treated merely as means" supports "It is wrong to harvest one person's organs to save five." |
| Conflicts | P entails the denial of J — if P is true, J should not hold. | "The right action maximizes aggregate well-being" conflicts with "It is wrong to harvest organs from one to save five" (since harvesting maximizes lives saved). |
| Undermines | P makes J less plausible without directly contradicting it — e.g., P suggests the considerations behind J are less weighty than assumed. | "Minor harms are morally negligible when they prevent major harms" undermines "Every act of deception is morally significant." |
| Depends | J presupposes P — the judgment only makes sense or holds if the principle is accepted. | "This distribution of resources is unjust" depends on some principle of distributive justice being in play. |

### Principle → Principle

| Relation | Description | Example |
|---|---|---|
| Supports | P₁ entails or strengthens P₂ — accepting P₁ gives reason to accept P₂. | "All persons have equal moral worth" supports "Resources should be distributed to give everyone a fair share." |
| Conflicts | P₁ and P₂ yield contradictory prescriptions in some cases — they cannot both be fully maintained. | "Always maximize aggregate welfare" conflicts with "Never violate individual rights, regardless of consequences." |
| Undermines | P₁ reduces the plausibility of P₂ without direct contradiction — e.g., P₁ undercuts the rationale that makes P₂ attractive. | "Moral intuitions are unreliable products of evolutionary pressures" undermines "We should trust our strong moral intuitions as evidence." |
| Depends | P₁ presupposes P₂ — P₁ loses its grounding if P₂ is withdrawn. | "We should redistribute wealth to ensure equal opportunity" depends on "Equal opportunity is a requirement of justice." |

### Theory → Principle

| Relation | Description | Example |
|---|---|---|
| Supports | T provides theoretical grounding for P — explains why P is plausible or well-founded. | "Human beings possess rational autonomy" supports "Persons must never be treated merely as means." |
| Conflicts | T is incompatible with P — if T is true, P cannot hold. | "There are no moral facts, only preferences" conflicts with "Some moral principles are objectively true." |
| Undermines | T reduces the plausibility of P without outright incompatibility. | "Moral psychology research shows people are strongly biased toward in-group favoritism" undermines "We owe equal moral consideration to all persons regardless of proximity." |
| Depends | P presupposes T — the principle requires the theory to be in place. | "We are obligated to reduce suffering in future generations" depends on "Future persons have moral status." |

### Theory → Judgment

| Relation | Description | Example |
|---|---|---|
| Supports | T provides reason to trust J — e.g., explains why the intuition behind J is reliable or well-grounded. | "Moral emotions like empathy are generally reliable guides in face-to-face contexts" supports a judgment about interpersonal harm. |
| Conflicts | T implies J is unreliable or mistaken — the theory gives reason to reject the judgment. | "Moral intuitions about large numbers are systematically unreliable" conflicts with a judgment based on intuitions about large-scale policy. |
| Undermines | T reduces confidence in J without implying it is outright wrong. | "People tend to confuse disgust with moral wrongness" undermines a judgment driven primarily by disgust reactions. |

### Theory → Theory

| Relation | Description | Example |
|---|---|---|
| Supports | T₁ strengthens or provides evidence for T₂. | "Neuroscience shows that moral reasoning involves both emotional and rational processing" supports "Moral judgments are not purely rational." |
| Conflicts | T₁ and T₂ are incompatible — both cannot be held. | "Moral realism: there are mind-independent moral facts" conflicts with "Moral anti-realism: moral claims are expressions of attitudes, not facts." |
| Undermines | T₁ weakens T₂ without flat incompatibility. | "Cross-cultural moral convergence on some norms" undermines "Morality is entirely culturally relative." |
| Depends | T₁ presupposes T₂. | "Psychological continuity theory of personal identity" depends on "Persons persist over time in some meaningful sense." |

## Usage Notes

- When a new element is added, walk through the relevant rows and columns of this matrix against **every existing element**.
- A single pair of elements can have **multiple relations** (e.g., P supports J in one respect but undermines it in another). Record each separately.
- Relations are **directional**: "P1 supports J1" is not the same as "J1 supports P1." Check both directions.
- When in doubt about whether a relation exists, **include it** with a brief explanation. The user can reject it during a review round.
- This is the single most important step for maintaining a complete and useful state. Missing connections directly degrade the quality of coherence evaluation.
